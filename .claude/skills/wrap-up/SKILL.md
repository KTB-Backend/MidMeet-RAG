# wrap-up — 세션 마무리 문서 동기화

Claude Code의 **세션 종료 전 문서 최신화** 역할을 고정하는 스킬이다.
이번 대화에서 내려진 결정·변경이 정본 문서에 빠짐없이 반영됐는지 감사하고,
**사용자 협의를 받아** 최신화한 뒤 종료를 안내한다.

수동 호출 스킬이다. 사용자가 세션을 끝내려는 신호("끝낼게", "마무리하자")를 보이거나 `/wrap-up`을 부를 때 실행한다.

## 절차

1. **변경·결정 수집**
   - `git status`·`git diff`·`git diff --staged`로 **커밋됨 / 미커밋** 변경을 구분해 파악한다.
   - 이번 대화에서 내려진 **설계·범위·데이터·스코어링 결정** 중 문서에 아직 안 박힌 것을 식별한다. (코드 변경뿐 아니라 "말로만 합의된 결정"도 포함)

2. **정본 대조 감사** — [`project-brief.md`](../../../docs/product-specs/project-brief.md)가 진실의 원천이다. 다음 정본과 대조한다:
   - `project-brief.md` §5 범위 / §6 스택 / §8 의사결정 표
   - `docs/design-docs/architecture.md` — 모듈 경계, 설정 주입표(환경변수), §13 TBD
   - `docs/design-docs/rag-design.md` — 스코어링·검증·구현 순서
   - `docs/design-docs/data-design.md` — 스키마·검증 심각도·데이터 정책
   - `docs/exec-plans/task-plan.md` — 진행 현황·S0~S8 체크리스트
   - 불일치 유형: **(a)** 결정했는데 정본에 없음 / **(b)** 코드가 문서보다 엄격하거나 다름 / **(c)** 경로·표기 불일치 / **(d)** 미커밋 변경.

3. **최신화 후보 보고 + 승인 요청**
   - 항목별로 **무엇을 / 어디에(파일:섹션) / 왜**를 표로 제시한다.
   - `AskUserQuestion`으로 협의한다(전체 반영 / 일부 선택 / 생략).
   - **미확정(TBD) 기술을 임의로 확정·제안하지 않는다.** brief와 코드가 충돌하면 충돌 지점을 먼저 보고하고 brief를 우선한다.

4. **승인분만 반영**
   - 승인된 **문서만** 수정한다.
   - **구현 코드는 수정하지 않는다.** 코드 변경이 필요하면 `/codex-task`로 위임 프롬프트를 만들어 안내한다(역할 경계 유지).

5. **마무리 안내**
   - 미커밋 변경을 요약하고 **커밋을 권장**한다(커밋은 사용자가 직접 한다).
   - 기억할 가치가 있는 워크플로·결정이 있으면 메모리 저장을 제안한다.
   - **Claude는 세션을 직접 종료하지 못한다.** "이제 `/clear` 또는 exit 하셔도 됩니다"로 안내하고 끝낸다.

## 출력 형식

```
## 세션 마무리 감사

### 이번 세션 변경·결정
- 커밋됨: ...
- 미커밋: ...
- 대화에서 합의됐으나 문서 미반영: ...

### 정본 대조 — 최신화 후보
| # | 항목 | 무엇을 | 어디에 (파일:섹션) | 유형(a/b/c/d) |
|---|------|--------|--------------------|----------------|
| 1 | ...  | ...    | ...                | ...            |
```

이어서 `AskUserQuestion`으로 "전체 반영 / 일부 선택 / 생략"을 협의한다. 승인 후:

```
## 반영 완료
- <파일>: <한 줄 요약>

## 종료 전 체크
- 미커밋: <목록> → 커밋 권장
- (선택) 메모리 저장 제안: <항목>
- 이제 /clear 또는 exit 하셔도 됩니다.
```

## 절대 규칙

- 정본은 `project-brief.md`다. 충돌 시 brief를 우선하고, 충돌 지점을 먼저 보고한다.
- **승인 없이 문서를 수정하지 않는다.** 구현 코드는 이 스킬에서 수정하지 않는다(필요 시 `/codex-task` 위임).
- 미확정(TBD) 기술을 임의로 확정하지 않는다.
- Claude는 세션을 직접 종료할 수 없다 — 마지막에 종료 방법만 안내한다.
